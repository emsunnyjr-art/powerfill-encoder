Web App URL (from Apps Script)
Data goes to your Google Sheet automatically. Free & unlimited. See setup guide below.
📌 Free Google Sheets Setup
1. Open Google Sheets → create new sheet
2. Extensions → Apps Script
3. Paste the doPost() script (see README in your GitHub repo)
4. Deploy → New deployment → Web App
5. Set "Anyone can access" → copy the URL → paste above
6. Done! All shifts go to your sheet for free ✅
📌 GitHub Pages Deployment (Free)
1. Create repo: powerfill-encoder
2. Upload this index.html file
3. Settings → Pages → Branch: main / root
4. Your app URL: username.github.io/powerfill-encoder
5. Bookmark it on your phone as a PWA — it works offline! 📱
